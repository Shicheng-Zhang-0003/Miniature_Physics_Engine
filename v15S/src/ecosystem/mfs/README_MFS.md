# MFS in the kernel ecosystem tree

**Location:** `v15S/src/ecosystem/mfs/` (this folder) inside the kernel
module-ecosystem handling folder `v15S/src/ecosystem/`
(`mpe_ecosystem.h/.c` + registry live one level up).

This is the single home for everything MFS-ecosystem. There are no forks:
the 535-line `mfs_ecosystem/modules/mfs_module_1.*` older sibling was
retired during the move (identical physics to the canonical 703-line fork
kept here; delta was comments/attributes/enum names plus a dlopen
constructor that self-DoSed attach via a duplicate registry insert).
Do not reintroduce it.

## What lives here

| File | Role |
|---|---|
| `mfs_module_1.c/.h` | Canonical MPI `generic` tick module `mfs-simulator` 1.0 (field + mecanum robot + intake + shooter + 16 balls). `deterministic=false` (libm + live gamepad; route trig through `core/det_math.h` before claiming true). |
| `mfs_module_1_test.c` | Attach→100-tick→detach test (field lookup by id, null-safe chassis, move/rpm/ball gates). |
| `mfs_ecosystem.c` | MEI wrapper bundling Module 1 (`mfs-simulator` ecosystem desc, `deterministic=false`). Config/command hooks are stubs returning -1. |
| `mfs_internal.c/.h` | Private static registry for that bundling (8 slots). `s_module_count`/`mfs_module_registry_t` dead; `clean`/`test` targets in the old makefiles were broken — consolidated here. |
| `Makefile` | Standalone fat-link build (`-I` on engine + robotics_backup; engine+robot stacks statically inside, like the originals). |

## What deliberately stays outside

- `v15S/src/ecosystem/mpe_ecosystem.*` — kernel MEI registry (parent dir, not MFS).
- `v15S/robotics_backup/` — tracked FTC robot library (`robotics/`, `gamepad/`, `tests_robotics/`, `plugins/mpe_ftc.so` build output). MFS modules compile against it via `-I$(RB)` and include it as `robotics/...` / `gamepad/...` (never `../`-relative). Moving it would churn every include and `build_tests.sh`; it is already its own distinct folder.
- `v15S/src/plugins/*.so` — gitignored build exhaust, regenerated by builds.

## Build

From this folder: `make` (both `.so`), `make test` (module test), `make clean`.
From `v15S/src`: `make mfs_ecosystem.so` (wired to this folder; see `src/makefile`).
